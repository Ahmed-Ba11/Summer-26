# فحص المتصفّح — المساعد الذكي

```bash
npm run verify:assistant
```

أمرٌ واحد يشغّل كل شيء: سيرفر Laravel، وVite، ومستخدم فحص مؤقّت،
وChromium بلا واجهة — ثم ينظّف كل ما أنشأه. **لا يمسّ أي بيانات قائمة**،
ولا يشغّل `migrate` ولا أي أمر يُسقط جدولاً.

الخروج بـ`0` إن نجحت كل الفحوص، وبـ`1` إن فشل واحد — فيصلح للـCI.

---

## لماذا متصفّح أصلاً

تسعة من معايير قبول المهمة لا تُختبر خارجه، وثلاثة منها لا يثبتها فحص
العين مهما طال:

| المعيار | لماذا لا يكفي النظر |
|---|---|
| النصّ يصل تدريجياً | العين ترى نصّاً يظهر، ولا تميّز «تدريجياً» عن «دفعةً بعد ثانية». المراقب يسجّل كل رندرة بطابعها الزمني. |
| `DOMPurify` يعمل | النظر يثبت أن الثغرة لم تُستغَلّ في تلك اللحظة فقط. الإثبات أن نبضة مزروعة عمداً لم تنفجر. |
| Console نظيف | تحذير واحد يضيع بين رسائل Vite. |

هذا الفحص هو ما كشف أن `DOMPurify` يجرّد `onerror` **ويُبقي** `<img>`،
فيظهر وصف المستخدم صورةً مكسورة لا نصّاً. لم يكن ليُرى بغير قياس.

## الملفات

| الملف | الدور |
|---|---|
| `assistant.mjs` | الفحص نفسه — ٤٠ تحقّقاً في تسعة أقسام |
| `probe-user.php` | إنشاء/حذف مستخدم الفحص وعملياته (فيها واحدة بوصف خبيث متعمَّد) |
| `screenshots/` | لقطات كل مرحلة (خارج git) |
| `last-run.json` | نتيجة آخر تشغيلة كاملة: كل فحص، وكل رسالة Console، وكل رندرة (خارج git) |

## ملاحظات بيئة تفسّر ما قد يبدو غريباً

**Vite ليس اختيارياً هنا.** `php artisan serve` أحادي العامل، و
`PHP_CLI_SERVER_WORKERS` يعتمد على `fork` فيردّ ويندوز
«forking is not supported on this platform». المتصفّح يفتح عدّة منافذ
keep-alive للأصول فيخنق العامل الوحيد، ويتعلّق أول انتقال تالٍ. تشغيل
Vite ينقل الأصول إليه (Node، متزامن) فلا يبقى على PHP إلا المستند
وطلبات Inertia والبثّ. وهو الإعداد الذي توصي به المواصفة أصلاً.

**عنوان Vite يُقرأ من `public/hot` لا يُفترض.** Vite يستمع على `[::1]`
على هذا الجهاز، فسؤال `127.0.0.1` يرجّع لا شيء ويبدو كأنه لم يبدأ.

**الفحص يغلق الألواح المفتوحة قبل النقر.** `SalaryCloseSheet` تفتح نفسها
لمن انتهت فترة راتبه، وطبقة التعتيم تبتلع كل نقرة. هذا سلوك التطبيق
الصحيح، والمستخدم يغلقها أولاً — وكذلك الفحص.

**المنافذ تُحرَّر قبل كل تشغيلة.** `npm run dev` غلافٌ حول Vite، وقتل
الغلاف لا يقتل ابنه دائماً على ويندوز؛ بلا التحرير تفشل كل تشغيلة تالية
بـ«Port already in use» ويبدو الخلل في الفحص لا في بقايا العملية.

## ما لا يغطّيه

- **حدّ الاستخدام** (٢٠/ساعة · ١٠٠/يوم) — يحتاج ٢٠ استدعاءً حقيقياً
  للمزوّد. اختُبر بـcurl بملء الدلو يدوياً، ولم يُدرَج هنا لئلّا تصرف كل
  تشغيلة عشرين رسالة من مفتاح مشترك.
- **مهلة الـ٣٠٠ ثانية** — تحتاج طلباً يتجاوز ٦٠ ثانية فعلاً.
- **عزل المستخدمين** — اختُبر على مستوى الأدوات داخل معاملة تُلغى، وهو
  الموضع الذي يُفرَض فيه العزل أصلاً.
