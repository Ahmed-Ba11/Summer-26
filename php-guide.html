مقدمة Java vs PHP الصياغة الأساسية المتغيرات والأنواع المصفوفات عبارات التحكم الدوال البرمجة الكائنية المتغيرات الفائقة النماذج والطلبات الجلسات والكوكيز قواعد البيانات (PDO) الملفات ميزات Laravel الشائعة

🚀 الانتقال من Java إلى PHP

دليل مبسّط يغطي أساسيات PHP لمن يعرف Java مسبقاً، مع التركيز على الفروقات الجوهرية والميزات المستخدمة بكثرة في إطار عمل Laravel.

مقدمة

💡 المفهوم الأهم: في Java البرنامج يُترجم كاملاً ثم يُنفّذ. في PHP يُنفّذ سطراً بسطر عند كل طلب HTTP، ثم "يموت" بعد انتهاء الطلب. كل طلب = بداية من الصفر.

Laravel هو أشهر إطار عمل PHP. هذه الميزات التي ستستخدمها يومياً مكتوبة بلغة PHP التي شرحناها أعلاه. فهمك لـ PHP الأساسية = فهمك لـ Laravel.

7. Middleware

أنابيب تمر من خلالها الطلبات — تشبه Filters في Java Servlet / Interceptors في Spring.

Laravel — Middleware// مثال: Middleware للتحقق من المصادقة
class Authenticate
{
    public function handle(Request $request, Closure $next)
    {
        if (!auth()->check()) {
            return redirect('/login');
        }

        return $next($request);  // مرر الطلب للمرحلة التالية
    }
}

// تطبيق middleware على Route
Route::get('/dashboard', [DashboardController::class, 'index'])
